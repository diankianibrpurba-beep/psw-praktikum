1. Git
Pengertian:
Git ialah sistem version control terdistribusi yang dipakai untuk melacak perubahan pada kode sumber selama pengembangan perangkat lunak.

Fungsi:
Menyimpan riwayat perubahan kode.
Memungkinkan kolaborasi tim secara bersamaan tanpa problem.
Memudahkan rollback ke versi sebelumnya jika terjadi error.
Mengelola branch untuk pengembangan fitur secara terpisah.

2. HTML (HyperText Markup Language)
Pengertian:
HTML merupakan bahasa markup standar untuk membuat struktur dasar halaman web.

Fungsi:
Menentukan elemen dan konten pada halaman web (teks, gambar, tabel, video, dll.).
Memberikan kerangka dasar yang akan dihias dengan CSS dan dihidupkan dengan JavaScript.
Mengatur struktur hierarki konten agar mudah dibaca oleh browser dan mesin pencari.

3. CSS (Cascading Style Sheets)
Pengertian:
CSS adalah bahasa yang digunakan untuk mengatur tampilan dan gaya halaman web.
Fungsi:
Mengatur warna, font, ukuran, dan tata letak dari elemen HTML.
Membuat desain supaya tampilan menyesuaikan berbagai perangkat.
Memisahkan konten (HTML) dari desain, agar kode lebih rapi dan mudah dikelola.

4. JavaScript (JS)
Pengertian:
JavaScript adalah bahasa pemrograman yang dipakai untuk membuat halaman web menjadi lebih interaktif dan dinamis.

Fungsi:
Mengatasi interaksi pengguna (klik, input, animasi, dll.).
Memanipulasi elemen HTML dan CSS langsung (DOM manipulation).
Mengambil dan transfer data ke server tanpa memuat ulang halaman (AJAX).
Dipakai juga di luar browser, contohnya dengan Node.js untuk backend.
